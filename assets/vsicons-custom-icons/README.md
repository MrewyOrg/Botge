# Discord folder icon

`folder_type_discord.svg` and `folder_type_discord_opened.svg` are identical, unmodified copies of
Discord's official [symbol asset][symbol], downloaded on 2026-11-08 from its
[brand assets page](https://discord.com/branding).

The symbol identifies Discord integration folders beside their names in VS Code; it is not Botge's
logo and does not imply Discord endorsement.
